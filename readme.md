## 📖 عن المشروع

**عبقري اليوم** هي لعبة ألغاز ذكاء تفاعلية مفتوحة المصدر، مصممة لتنشيط العقل وتحدي الذاكرة والمنطق. تأتي مع **أداة ذكاء اصطناعي مدمجة** تحلل أداءك وتقدم اقتراحات ذكية.

## ✨ الميزات

- 🧩 **5 أنواع من الألغاز**: رياضيات، منطق، كلمات، ذاكرة بصرية، تذكر الأضواء
- ⭐ **نظام نجوم ومستويات**: كل 5 نجوم تفتح مستوى جديد
- ⏱️ **مؤقت ضغط**: يزيد الإثارة مع بونس للسرعة
- 💡 **تلميحات**: 3 تلميحات تزيد مع كل مستوى
- 🔥 **نظام كومبو**: إجابات متتالية صحيحة = مكافآت إضافية
- 🤖 **ذكاء اصطناعي مدمج**: يحلل أنماطك ويقترح إجابات ذكية
- 📊 **تحليل الأداء**: إحصائيات عن نقاط قوتك وضعفك
- 🌐 **مفتوح المصدر**: قابل للتعديل والإضافة بسهولة
